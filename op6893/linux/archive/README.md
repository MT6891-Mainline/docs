# op6893 Linux 归档

这些记录随 op6893 内核适配保存，迁移基线是内核提交
`3322752a820e4546b17bf193293579867341ff8b`。其中的阶段性结论以各篇所述
镜像和测试环境为准；当前入口见 [Linux 支持状态](../README.md)。

- [原始开发检查点](CHECKPOINT.md)、[硬件路线图](HARDWARE-PLAN.md)
- [无线初始化](WIFI-INITIALIZATION.md)、[固件分析交接](WIFI-REVERSE-ENGINEERING.md)、[无线固件清单](wifi-binary-manifest.json)
- [基带计划](MODEM-PLAN.md)、[基带放行和数据面](MODEM-BOOT-RELEASE.md)、[SCP/MD 热启实测](MODEM-SCP-RESET-RESTORE.md)
- [逐轮报告与证据](evidence/)：测试日志、结构化测量数据、校验和及源码审计摘录

历史记录中的 `mt6893-direct/`、绝对路径及未收录的附件指向当时的本地
工作区。镜像、rootfs 和设备私有文件没有随文档迁移；日志中的已知设备标识
和 MAC 地址已删去。测试与运行脚本仍在 Linux 仓库的
`Documentation/arch/arm64/op6893-bringup/tools/`。运行历史命令时，以
对应版本的内核工作树为当前目录。文中的 `tools/<文件>` 是上述目录的简写。
