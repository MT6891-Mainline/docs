# chopin 7.2.8 → 7.3 基线迁移

> 把 7.2.8 上的 chopin 移植（音频、蓝牙、WiFi、GPU、显示、板级 DT 等 102 个提交）
> 通过 patch 迁移到 **Linux 7.3** 全新基线。
> 状态（2026-10-24）：迁移完成、内核与 DTB 编译通过；**已上机验证**，内核启动正常、WiFi 恢复（见下文「上机问题」）。

## 迁移方法

1. 解压 7.3 到 `git/chopin-linux-7.3`，`git init` 后把纯 7.3 树提交为基线；
2. 在旧仓库 `git format-patch 2ca60ae..HEAD`（`2ca60ae` = 7.2.8 纯净基线）
   生成 **102 个 patch**（37 MB）；
3. 新仓库 `git remote add ref728 ../chopin-linux-7.2.8 && git fetch ref728`
   —— 让 `git am --3way` 能找到 patch 的 pre-image blob；
4. `git am --3way <patches>`，冲突逐个解决。

## 上机问题（7.3）

**WiFi 起不来**：init 在 rootfs 模式下把 `fwload` 放在诊断 dump 之后，7.3 上这些
dump 要 35 秒，而 wlan 驱动 2 秒就开始请求 NVRAM、conninfra pre-cal 只等 ~30 秒，
于是 pre-cal 超时、芯片被留在半上电状态（`bus might hang`、`wm pc=0x495a`），
没有 wlan0。

修复（port 提交 `9955fd5`）：init 解析出 rootfs 设备后立刻 `fwload`，再继续诊断。
修复后 `wlan0` 正常、拿到 DHCP 地址。

> 系统里还会看到 `wlan1`：这是驱动 `CFG_SUPPORT_DUAL_STA=1`（6893 默认）生成的
> 第二个 STA 接口（独立 MAC，共用同一个 wiphy），用于双频并发；平时 down 着，
> **保留**，需要时可 `nmcli dev set wlan1 managed yes` 后单独连第二个网络。
